# 防災・避難所案内アプリ

Flask 製の防災情報アプリです。トップページで住民向け指示と青森市の気象情報を確認でき、避難所の検索・比較、管理者による避難所登録・編集、指示ボードを利用できます。

## 起動

```sh
python -m pip install -r requirements.txt
python app.py
```

## 管理者・セッション設定

ローカル開発ではリポジトリ直下の Git 管理外 `.env` から `ADMIN_PASSWORD` を読み込みます。任意でログイン名を `ADMIN_USERNAME` に指定できます。環境変数が設定されている場合は `.env` より優先されます。パスワード未設定時はログインを受け付けません。本番では `.env` に依存せず、デプロイ環境の秘密設定に十分に強いパスワードを登録してください。短いパスワードはローカル開発用途に限ってください。

本番環境では、十分にランダムな `FLASK_SECRET_KEY` を秘密情報管理機能から設定してください。未設定時は起動ごとに一時的な鍵を生成するため、再起動後に既存セッションを引き継げません。ソースコードやリポジトリに秘密値を保存しないでください。

開発サーバーは既定でデバッグ無効です。ローカル開発時のみ必要に応じて `FLASK_DEBUG=1` を設定してください。本番環境では有効にしないでください。

## 気象情報の地域設定

既定値は青森県・青森市です。必要に応じて `JMA_PREFECTURE_CODE`、`JMA_PREFECTURE_NAME`、`JMA_AREA_NAME`、`JMA_AREA_CODE`、`JMA_WARNING_URL` を環境変数で上書きできます。

トップページの `/api/disaster_information` は気象庁の警報・注意報と有効な住民向け指示を統合し、新着順で返します。道路・現地情報は接続先がないため、データを生成せず未接続として表示します。

避難所の位置は、管理者が避難所登録・編集画面の地図クリック、緯度・経度入力、または国土地理院地名検索の候補選択で指定できます。候補検索は `/api/geocode` を使用し、ログイン必須です。候補選択だけでは保存されず、登録・更新フォームの送信後に反映されます。地名検索は通信環境と国土地理院サービスに依存し、タイムアウトや検索間隔制限時も地図クリック・座標の直接入力を利用できます。地図タイルは OpenStreetMap から取得します。

## データ保存

避難所と指示は `bousai_app/data/` 配下の UTF-8 JSON ファイルに保存されます。ローカルなど永続ディスクを使う環境では再起動後も保持されます。Vercel 等の書き込み可能領域が一時的なサーバーレス環境では、永続性が保証されないため、本番運用には永続データベース等への移行が必要です。

```sh
python -m unittest discover -s tests -v
```
